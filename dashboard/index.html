📖 Installation & Architecture Specs

How to Install Extensions in Shiru App

  1. Open the Shiru App on your device.
  2. Navigate to Settings → Extensions / Sources.
  3. Click Add Repository or Add Source.
  4. Paste either the master repository shorthand `gh:user/shiru-anime-extensions` or direct URL `https://raw.githubusercontent.com/user/shiru-anime-extensions/main/index.json`.
  5. Click Save. Shiru will automatically fetch and enable your anime torrent sources!

Extension System Specs

Every extension implements the official TorrentSource interface:

export class TorrentSource {
  single(query: TorrentQuery): Promise<TorrentResult[]>
  batch(query: TorrentQuery): Promise<TorrentResult[]>
  movie(query: TorrentQuery): Promise<TorrentResult[]>
  validate(): Promise<boolean>
}
